# GenAI Project

## Description

GenAI is an advanced project focused on the development and implementation of Large Language Models (LLMs). This repository contains the logic and codebase for various models designed to tackle a broad range of tasks within natural language processing, generation, and understanding.

## Usage

Here is a quick start example of how to use the GenAI models:

```python
from genai import model

# Initialize the model
genai_model = model.GenAIModel()

# Generate text
text = genai_model.generate("Example prompt")
print(text)
```

Replace "Example prompt" with your desired input.

## Folder Structure

- [Enquirious Portal Experiments](Enquirious%20Portal%20Experiments): Contains Jupyter notebooks for experiments related to the Enquirious Portal.

- [RAG](RAG): Holds the code for the Retrieval-Augmented Generation component of the project.
- [SQLChallenger_bot](SQLChallenger_bot): Contains the code for a bot designed to handle SQL challenges.

- [Streamlit](Streamlit): Contains Streamlit applications for LLMs.
