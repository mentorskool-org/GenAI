# OpenAI Experiments

Welcome to the OpenAI Experiments directory! This repository contains various experimentations performed using the OpenAI API, covering a wide range of functionalities such as text-to-speech (TTS), embeddings, text generation, vision, and speech-to-text.

## Directory Structure

The repository is organized into subdirectories based on the type of experiments conducted. Each subdirectory contains code, resources, and references specific to that type of experiment.

### Subdirectories

- [**TTS (Text-to-Speech)**](TTS): Contains experiments related to converting text into speech.

## TTS (Text-to-Speech)

This subdirectory contains various experiments related to converting text into speech using OpenAI's models.
